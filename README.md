# Book Club downloads

Book Club is a private reading app for friends. This page only hosts the
installers; the app updates itself from here.

**Download the latest version from [Releases](../../releases/latest).**

## Android
1. Download `BookClub-Android.apk` on your phone and open it.
2. If asked, allow your browser to install apps, then tap **Install**.
3. Future updates: the app tells you when a new version is ready.
   Tap **Update now**, then **Update** on Android's install screen.

## Windows
1. Download `BookClub-Windows.zip` and unzip it somewhere in your user folder
   (for example `Documents\Book Club`).
2. Run `BookClub.exe`. If SmartScreen warns about an unknown app, choose
   **More info → Run anyway**.
3. Future updates: the app offers them on start; it downloads, swaps its
   files and restarts by itself.
